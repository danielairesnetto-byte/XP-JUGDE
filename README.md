# XP-JUGDE
O XP JUDGE é um dispositivo para RPGs projetado para calcular e distribuir Pontos de Experiência (XP) de forma rápida e precisa. Ele automatiza fórmulas complexas considerando dano, cura e ações táticas dos jogadores, garantindo uma divisão justa e imparcial ao final de cada sessão sem desacelerar a narrativa do jogo na mesa.
